# EchoSubs 界面改造

目标是让订阅与付款更易扫读，采用 EchoSubs 自定义设计体系。Flutter 底层表单、焦点和无障碍能力作为适配层保留；界面不使用 Material 的默认视觉、导航栏、悬浮按钮或水波纹。

## 视觉约定

- 浅色：冷灰画布 F3F6F8、白色面板 FFFFFF、墨色文字 172B36、次级文字 586B78、青绿强调 08776F、细边界 DCE4E9。
- 深色独立定义语义色，使用蓝灰面板、浅色正文和低饱和青绿。金额和正文分别校验对比度，不整体降低文字透明度。
- 统一 4/8 间距，面板圆角 12、控件圆角 8；表单使用常驻标签，主操作与次操作有明确层级。
- 使用系统字体和自绘矢量符号，不下载字体，不新增运行时或 UI 包。金额对齐并使用等宽数字。
- 微动效约 140–160ms，减弱动画模式直接切换；按下、悬停和键盘焦点都应可见。

## 布局与交互

- 桌面使用紧凑侧栏和独立工具栏，内容按可用宽度自适应；手机使用自定义底部导航，触达区域至少 48dp。
- 总览优先显示到期、冲突和同步风险，再展示预测与实际支出。按币种分列；不将估算、累计付款或赠送权益混为本月支出。
- 订阅列表分清服务、状态、金额和日期。总览的日期标记是主要视觉识别，日期与风险文案保留完整含义。
- 搜索、分类和包含归档筛选均继续工作。空状态提供明确下一步；已有草稿、冲突保护和键盘保存区保留。
- 同步、提醒、恢复和密钥确认继续使用既有业务接口；新视觉不改变认证、存储、配对或通知权限。

## 实施与验证

先完成共享语义色、图标、表单和提示，再调整导航、总览、列表及设置等页面。使用独立临时账本与虚构订阅生成预览，不读取用户现有账本或恢复密钥。检查窄屏、桌面、浅深色、大字、键盘以及关键操作回归，最后构建双端测试包。

样式检索第一次返回营销漏斗，不适合原生账本；收窄到 productivity dashboard 的 style 域后得到适用于专业工具的极简网格建议，仅采用经核对的层级、留白与可访问性原则。未采用营销配色、网页引导或更换路由库的建议。
